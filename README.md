# Site-Familia

Site de memória e história familiar. Front-end em Vite + JavaScript puro,
dados e mídia no Supabase.

## Rodando localmente

```bash
npm install
cp .env.example .env   # preencha com a URL e a anon key do seu projeto Supabase
npm run dev
```

Veja `CLAUDE.md` para detalhes de arquitetura, e o final desse arquivo
para o passo a passo de configuração do projeto Supabase (SQL, bucket de
Storage, usuário admin).
